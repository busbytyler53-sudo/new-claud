# Ritmo

Clean clothing brand. Replaces the earlier drafts (Sottovoce, Solano, Agosto, Tenure, Nove), all still in git history.

Story: Ritmo is Italian for rhythm. One wardrobe that keeps time with the whole day.

- Name: Ritmo
- Monogram: R.
- Emblem: a metronome
- Sign-off: In Tempo ("in time" and "on time")

Lines, each a beat in the day:
- Sport (09:00): activewear
- Giorno (13:00): smart casual
- Sera (21:00): date night
- Strada (any time): streetwear

`logos/` has every mark as outlined SVG in black, chalk and stone: wordmark, lockup, r, metronome,
stamp, label, and line lockups (line-sport, line-giorno, line-sera, line-strada).
`brand-sheet.html` is the brand sheet. `source/gen7.py` and `source/build7.py` regenerate everything
(needs fonttools and Archivo from Google Fonts in `source/fonts/`).

Colours: Chalk #F1EFEA, Oat #DDD5C6, Stone #B5B0A6, Olive #7D7E68, Navy #232B38, Black #1F1F1D.
