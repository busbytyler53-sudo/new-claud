# Solano

Clean everyday clothing brand with Italian heritage. Earlier drafts are in git history.

Story: Solano is the old name for a warm summer wind off the Mediterranean. It goes everywhere, all day.
The clothes do the same. Tagline: "Va dove vai" (goes where you go).

- Name: Solano
- Short name: Sol. (sol is the sun)
- Wordmark: Bodoni (the heritage), everything else in a wide sans (the clean)
- Crest: Solano Club, Italia, MMXXVI
- Emblem: sun and wind (a sun with two wind lines through it)
- Community: Solano Club (Sunday run club, first access to drops)

Lines:
- Sport: activewear, the Solano Club kit
- Giorno: smart casual
- Sera: date night
- Strada: streetwear

`logos/` has every mark as outlined SVG in black, chalk and stone: wordmark, lockup, sol, emblem,
club (heritage lockup), crest, label, and line lockups. `brand-sheet.html` is the brand sheet. `source/gen9.py` and
`source/build9.py` regenerate everything (needs fonttools plus Archivo and Bodoni Moda from Google Fonts in `source/fonts/`).

Colours: Gesso #F1EFEA, Avena #DDD5C6, Pietra #B5B0A6, Oliva #7D7E68, Notte #232B38, Nero #1F1F1D.
