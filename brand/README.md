# Solano

Clean everyday clothing brand. Earlier drafts are in git history.

Story: Solano is the old name for a warm summer wind off the Mediterranean. It goes everywhere, all day.
The clothes do the same. Tagline: "Goes where you go."

- Name: Solano
- Short name: SOL. (sol is the sun)
- Emblem: sun and wind (a sun with two wind lines through it)
- Community: Solano Club (Sunday run club, first access to drops)

Lines:
- Sport: activewear, the Solano Club kit
- Giorno: smart casual
- Sera: date night
- Strada: streetwear

`logos/` has every mark as outlined SVG in black, chalk and stone: wordmark, lockup, sol, emblem,
club, label, and line lockups. `brand-sheet.html` is the brand sheet. `source/gen8.py` and
`source/build8.py` regenerate everything (needs fonttools and Archivo from Google Fonts in `source/fonts/`).

Colours: Chalk #F1EFEA, Oat #DDD5C6, Stone #B5B0A6, Olive #7D7E68, Navy #232B38, Black #1F1F1D.
